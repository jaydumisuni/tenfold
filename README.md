# Tenfold

Tenfold is a model-free machine execution force for completing an already-approved engineering roadmap at maximum safe parallelism.

Tenfold is not an architect, an autonomous product manager, a swarm that invents the next steps, a collection of mandatory LLM agents, or a replacement for Sergeant. Its job begins after the roadmap/blueprint is sufficiently defined.

## Core principle

> Spend intelligence on judgment; spend compute on labour.

Tenfold uses a deterministic Foreman, trained execution Officers, trained bounded Privates, milestone Councils, optional external assurance, and optional consultant AIs. Models are capabilities, not ranks or authorities.

The founding hierarchy is:

```text
Approved Blueprint / Roadmap
          |
      Tenfold Foreman
      model-free core
          |
   Execution Officers
          |
    Tenfold Privates
          |
       Facilities
          |
 structured evidence
          |
   Milestone Council
          |
 external assurance where required
          |
   next safe frontier
```

## Sergeant donor relationship

Sergeant is the primary organisational donor. Tenfold inherits the principles that training is shared while authority is not; Privates execute bounded work, Officers own specialist responsibilities, the field is reconciled through council/rebrief, and optional models amplify rather than become the system.

Tenfold applies that discipline to mass machine execution.
